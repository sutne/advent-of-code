### Setup

Using `pyenv` inside the `2025` folder:

```sh
pyenv install 3.13.9
pyenv virtualenv 3.13.9 aoc-2025
pyenv activate aoc-2025
pyenv local aoc-2025
python -m pip install --upgrade pip
pip install -r requirements.txt
```
